# Copilot API SDK 1.0.0

_Released 4 October 2026_

This is the first release you can use to manage accounts in the Copilot API. You create one client, give it your sign in token, and you can list, view, create, update, and delete accounts from your own code.

## Highlights
- **One client for the admin routes**: create a `CopilotAdminClient` with your API address, hand it any async token source (MSAL, Auth0, or your own), and every request carries your bearer token for you.
- **Full account management**: `client.accounts` lets you list every account, get one by its id, create one, update its name and logo, and delete it.
- **Mistakes caught before they are sent**: a blank name, a logo address that isn't http or https, or an id that isn't a valid UUID is rejected straight away, without calling the API.
- **Answers you can trust**: every response is checked against the shape the SDK expects, so unexpected data never quietly reaches your code.

## Improvements
- You can cancel any account call with an `AbortController` by passing `{ signal }` as the last argument.
- When a check fails you get a `ValidationError` that tells you whether your input or the API's answer was the problem, and lists each issue it found. If the API's answer to a create, update, or delete looks wrong, the change may already have gone through, so the error suggests you reload before you retry.
- Every SDK error now has a fixed `code` (`HTTP_ERROR`, `NETWORK_ERROR`, `AUTH_TOKEN_ERROR`, `VALIDATION_ERROR`), so you can tell errors apart reliably even when both the ES module and CommonJS copies of the package are loaded.
- The error classes and all the account types are now available from the package root, so one import gives you everything.

## Upgrade notes

You might like to build a fresh tarball with `pnpm pack` and install it in your project with `npm install /path/to/ics-ai-copilot-api-sdk-1.0.0.tgz`. The package now needs `zod` at run time, and npm installs it for you along with the tarball. Your TypeScript setup still needs a module resolution mode that reads `exports` (`nodenext`, `node16`, or `bundler`), the same as before.
